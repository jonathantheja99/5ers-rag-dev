# 🚀 The 5ers RAG Knowledge Base

Welcome to the **5ers RAG (Retrieval-Augmented Generation) Knowledge Base** repository!

This repository is the single source of truth for an automated AI Agent built on **Google AI Studio**. It aggregates and compiles comprehensive FAQ data from [The 5%ers](https://the5ers.com/faqs/) into a format that Large Language Models can easily digest.

## 🌟 What is this project?
The goal is a highly accurate, RAG-based AI assistant for The 5%ers platform. Since program rules, pricing, and FAQs change over time, this repository automates the extraction and compilation of that data.

Instead of manually feeding an AI updated information, this system:
1. **Scrapes** every English FAQ from The 5%ers WordPress REST API.
2. **Compiles** it into a single, clean markdown file (`knowledge_base/faq_data.md`) with verified operational rules pinned at the top.
3. **Integrates** directly into Google AI Studio as the ground truth context for the custom agent.

## 📂 Repository Structure

- `knowledge_base/faq_data.md` — **The compiled file you upload to Google AI Studio.** Generated; do not hand-edit.
- `knowledge_base/the5ers_master_kb.md` — Verified rules, exact formulas, and senior moderator rulings. Hand-maintained, and always written to the top of `faq_data.md`.
- `knowledge_base/the5ers_official_faqs.md` — The full official FAQ archive (212 articles). Regenerated by the scraper.
- `knowledge_base/architecture_and_pipeline.md` — Architecture and pipeline documentation.
- `backend/` — `scraper.py` (REST API crawler), `compiler.py` (merges the KB), `agent.py` (LangChain RAG prototype), `main.py` (FastAPI `/chat` + `/health`), `smoke_test.py` (ground-truth checks).
- `frontend/` — A glassmorphism-themed React/Vite chat UI prototype.
- `.github/workflows/scrape.yml` — Weekly GitHub Action that refreshes the knowledge base.

### Why the ordering matters
`faq_data.md` is built as **master KB first, then the FAQ archive**. The archive
contains older and marketing phrasings of the same topics, so anywhere the two
disagree, the master KB is the answer. `compiler.py` refuses to run without it,
and the workflow fails the build if the compiled output loses it.

Note that file order alone does **not** prioritise policy for vector search —
`backend/agent.py` additionally tags each chunk `tier=master` or `tier=archive`
and retrieves from both tiers on every query. See
`knowledge_base/architecture_and_pipeline.md`.

## 🔄 Refreshing the data

```bash
pip install -r requirements.txt

python backend/scraper.py            # writes knowledge_base/scraped/ for review
python backend/scraper.py --promote  # replaces the5ers_official_faqs.md
python backend/compiler.py           # rebuilds knowledge_base/faq_data.md
python backend/compiler.py --check   # verifies the compiled file is current
```

## ⚙️ Automated Updates

A **GitHub Action** triggers weekly (Sunday 00:00 UTC) and on demand via
*workflow_dispatch*. It scrapes, compiles, verifies the master KB survived, and
commits the result. The job needs `permissions: contents: write` — without it
`git push` fails with exit code 128.

## 🤝 Using with Google AI Studio

1. Go to [Google AI Studio](https://aistudio.google.com/).
2. Create a new prompt or agent.
3. Upload `knowledge_base/faq_data.md` as a knowledge source.
4. The agent will now have comprehensive knowledge of all Bootcamp, High Stakes, Hyper Growth, Summer Plan, and Futures programs.
